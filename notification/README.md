# notification
Java 25 and Spring Boot 4 CRUD REST API

## Setup
You need [JDK 25](https://adoptium.net/) (e.g. `brew install openjdk@25`). Gradle is provided by the wrapper.

## Building
`./gradlew clean build`

## Running
`./gradlew bootRun`

## Documentation
(default: http://localhost:8080)
